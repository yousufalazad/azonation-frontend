# Handoff notes

One short note per session, so the next session (Sonnet or Opus) can continue without
re-explaining. Name: `YYYY-MM-DD-<topic>.md`. Newest note = where to continue.

Start a new session with:

> Read CLAUDE.md, docs/ROADMAP.md and the newest note in docs/handoff/, then continue.

## Template

```
# <date> — <topic>

## Done
- …  (commits: frontend <sha>, backend <sha>)

## Half-finished
- …  (file, what is left)

## Next step
- …

## Open questions for the owner
- …

## Notes / gotchas found
- …
```
